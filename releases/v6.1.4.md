# Release v6.1.4
Date: 2026-11-17

## Description
This release fixes dialect validation. A dialect whose block begins and ends with the same tag (for example `DIV_TAG_LOOP_END_PREFIX` and `DIV_TAG_LOOP_END_SUFFIX` equal to the loop's begin) was accepted as valid, and a template using that block never finished rendering. `div::isValidCurrentDialect()` now refuses it for every block with a begin and an end, with a message naming the tags, so Div stops at once with "Current dialect is invalid". Dialects whose tags are only alike (the same prefix with another suffix, or a begin prefix that starts the end prefix) remain valid (#36).

It also corrects the version Div reports (`div::getVersion()` and `{$div.version}`), which still said 6.1.2, and the closing tag of the products loop in the example of section 2.10 of the documentation.
